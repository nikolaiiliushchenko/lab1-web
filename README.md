# Лабораторна робота № 6. Дані та динамічне формування DOM засобами JavaScript

## Тема та мета
- **Тема:** Масиви та об'єкти JavaScript. Динамічне формування контенту, пошук і фільтрація даних.
- **Мета:** Навчитися описувати предметні дані масивом об'єктів, перетворювати дані на HTML-картки, оновлювати DOM і реалізовувати пошук та фільтрацію без перезавантаження сторінки.

## Опис структури даних та рендерингу
У файлі `js/scripts.js` створено масив `items` із 8 об'єктів фільмів у трьох категоріях (`фантастика`, `комедії`, `драми`). Кожен об'єкт містить властивості:
- `id` — унікальний числовий ідентифікатор;
- `title` — назва фільму;
- `category` — категорія (жанр) для фільтрації;
- `description` — короткий опис сюжету та жанру;
- `image` — посилання на постер.

Статичні картки видалено з `index.html`. Функція `createCard(item)` формує HTML-розмітку картки за допомогою шаблонних рядків, а функція `renderItems(itemsToRender)` перетворює масив через `map()`, об'єднує рядки методом `join("")`, записує результат у `#item-grid`, оновлює лічильник `#results-count` та керує видимістю повідомлення `#empty-message` («Нічого не знайдено.»).

## Реалізація пошуку та фільтрації
Функція `applyFilters()` одночасно застосовує:
1. **Пошук без урахування регістру (`input`):** зчитує значення `#item-search`, прибирає зайві пробіли через `trim()`, переводить у нижній регістр через `toLowerCase()` та перевіряє входження тексту в назву або опис за допомогою `includes()`.
2. **Фільтр за категорією (`change`):** порівнює вибране значення `#category-filter` із полем `item.category` (або показує всі елементи при значенні `"all"`).
