# Лабораторна робота № 3. Компонування вебсторінки та створення форм

## Тема та мета
- **Тема:** Побудова макета вебсторінки засобами CSS Flexbox і Grid. Створення, оформлення та базова перевірка HTML-форми.
- **Мета:** Навчитися свідомо обирати Flexbox або Grid для компонування елементів, керувати напрямком, вирівнюванням і проміжками, а також створювати семантичну й доступну форму з підписами, різними типами полів і вбудованою HTML-перевіркою.

## Обґрунтування вибору Flexbox та Grid
- **Flexbox (`.main-nav`, `.main-nav ul`):** використано для одновимірного компонування горизонтального рядка навігації із вирівнюванням `align-items: center`, розподілом простору `justify-content: space-between` та проміжками `gap: var(--space)`.
- **Grid (`.card-grid`, `.request-form`, `.form-field`):** використано для двовимірної сітки з трьох карток фільмів (`grid-template-columns: repeat(3, minmax(0, 1fr))`) та впорядкування полів форми без додаткових `margin`.

## Структура та перевірка форми
Додано тематичну форму пошуку та рекомендації фільму (`.request-form`), яка містить:
1. Пошуковий запит (`input type="text"`, `id="query"`, `name="query"`) — перевірка `required` та `minlength="2"`.
2. Жанр (`select`, `id="genre"`, `name="genre"`) — перевірка `required`.
3. Формат показу (`select`, `id="format"`, `name="format"`) — перевірка `required`.
4. Кількість глядачів (`input type="number"`, `id="tickets"`, `name="tickets"`) — перевірка `required`, `min="1"`, `max="10"`.
5. Побажання до сеансу (`textarea`, `id="wishes"`, `name="wishes"`) — перевірка `required` та `minlength="5"`.
6. Кнопка відправлення (`button type="submit"`).

Усі поля пов'язані з видимими підписами `<label>` через атрибут `for`, мають стани `:focus-visible` та `:focus:invalid`.
