# Лабораторна робота № 4. Препроцесор SCSS та адаптивний дизайн веб-сторінки

## Тема, мета та короткий опис проєкту
- **Тема:** Препроцесор SCSS та адаптивний дизайн веб-сторінки.
- **Мета:** Навчитися організовувати стилі за допомогою SCSS, використовувати змінні, вкладені правила, міксини та модулі, компілювати SCSS у CSS і адаптувати макет наскрізного сайту для мобільних, планшетних і настільних екранів.
- **Опис проєкту:** Наскрізний вебсайт кінотеатру «Прем'єра» (Варіант 7) з інформацією про заклад, 3 картками фільмів у прокаті, розкладом сеансів та формою підбору фільму.

## Структура SCSS-файлів та використані можливості
Стилі поділено на модулі в папці `scss/` і підключено до головного файла через сучасне правило `@use`:
- `scss/_variables.scss` — partial-файл зі змінними кольорів (`$color-primary`, `$color-text`, `$color-surface`, `$color-background`, `$color-border`), відступів (`$space-sm`, `$space-md`, `$space-lg`), радіуса (`$radius-md`) та точок переходу (`$bp-tablet`, `$bp-desktop`).
- `scss/_mixins.scss` — partial-файл із параметризованим міксином `@mixin respond-from($breakpoint)` для генерації медіазапитів `min-width`.
- `scss/main.scss` — головний файл стилів, який підключає модулі (`@use "variables" as v;`, `@use "mixins" as m;`), використовує вкладеність селекторів у компонентах `.main-nav`, `.card`, `.button`, `.request-form` та батьківський селектор `&` для станів `:hover`, `:focus-visible` і `:focus:invalid`.
- `css/styles.css` — автоматично скомпільований CSS-файл, підключений до `index.html`.
