# Курсова робота. Вебзастосунок «Довідник країн»

## Короткий опис проєкту
- **Тема:** Розроблення вебзастосунку «Довідник країн» для пошуку та порівняння відомостей про країни світу.
- **Мета:** Закріпити практичні навички розроблення клієнтського вебзастосунку з використанням семантичної розмітки HTML5, препроцесора SCSS, адаптивного дизайну (Mobile-first) та динамічної роботи з даними у JavaScript (ES6+).

## Основні можливості (відповідно до ТЗ)
- **F1 (Перегляд каталогу країн світу):** Відображається адаптивна сітка карток із прапором, назвою країни, столицею та чисельністю населення.
- **F2 (Пошук та фільтрація за регіоном):** Реалізовано одночасний пошук за назвою чи столицею без урахування регістру та фільтрацію за регіонами (`Європа`, `Азія`, `Америка`, `Африка`, `Океанія`). За відсутності збігів виводиться повідомлення «Нічого не знайдено».
- **F3 (Детальна інформація про країну):** При натисканні кнопки «Детальніше» на картці відкривається блок із розширеними даними: столиця, регіон, населення, площа території, валюта та офіційна мова.
- **F4 (Сортування списку країн):** Користувач може відсортувати каталог за назвою (А–Я, Я–А) або за чисельністю населення (від більшого до меншого та навпаки).

## Використані технології
- **HTML5:** семантична структура сторінки, доступні елементи керування (`aria-expanded`, `aria-controls`, `aria-live`), вбудована валідація форми.
- **SCSS / CSS3:** модульна архітектура (`_variables.scss`, `_mixins.scss`, `main.scss`), CSS Grid та Flexbox, mobile-first адаптивність для екранів `360px`, `768px` та `1280px`.
- **JavaScript (ES6+):** динамічний рендеринг DOM із масиву об'єктів за допомогою `map()`, спільна фільтрація через `filter()`, сортування через `sort()` і `localeCompare()`, делегування подій кліку.

## Вимоги до середовища та джерело даних
- **Вимоги до середовища:** сучасний веббраузер (Chrome, Edge, Firefox), Node.js та npm (для компіляції SCSS у CSS), редактор VS Code із розширенням Live Server.
- **Змінні середовища:** додаткові змінні середовища (`.env`) та зовнішні ключі API не потрібні.
- **Джерело даних:** локальний структурований масив об'єктів `items` у файлі `js/scripts.js` (12 країн світу з даними про столицю, регіон, населення, площу, валюту, мову та прапор).
