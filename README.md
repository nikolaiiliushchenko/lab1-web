# Лабораторна робота № 2. Стилізація веб-сторінки засобами CSS

## Тема та мета
- **Тема:** Підключення каскадних таблиць стилів і базове оформлення HTML-сторінки наскрізного навчального проєкту.
- **Мета:** Навчитися підключати зовнішній CSS-файл, добирати селектори, застосовувати каскад та успадкування, використовувати модель коробки і CSS-змінні, оформлювати типографіку, навігацію, кнопки та картки контенту.

## Опис проєкту
Вебсторінка кінотеатру «Прем'єра» (Варіант 7) з інформацією про заклад, 3 однотипними картками фільмів у прокаті, розкладом сеансів та кнопкою бронювання.

## Перелік реалізованих змін
1. Створено та підключено зовнішній файл стилів `css/styles.css`.
2. Додано класи `site-header`, `main-nav`, `card`, `card-title`, `button`.
3. Оголошено 6 CSS-змінних у `:root`.
4. Застосовано `box-sizing: border-box`, властивості `margin`, `padding`, `border`, `border-radius`.
5. Оформлено 3 однотипні картки фільмів (`.card`) та кнопку (`.button`).
6. Додано стани `:hover` та `:focus-visible` для посилань і кнопки.
