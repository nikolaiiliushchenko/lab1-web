# Лабораторна робота № 5. Основи JavaScript. Взаємодія з DOM та подіями

## Тема та мета
- **Тема:** Підключення JavaScript до вебсторінки, пошук елементів у DOM, обробка подій та зміна стану інтерфейсу.
- **Мета:** Навчитися підключати зовнішній JavaScript-файл, знаходити наявні HTML-елементи, реагувати на дії користувача та змінювати класи й текстовий вміст елементів. Додати до наскрізного сайту інтерактивні можливості.

## Реалізовані інтерактивні можливості
1. **Показ і приховування додаткового блоку («Показати більше» / «Приховати»):**
   - Кнопка `.details-toggle` у секції «Про наш кінотеатр» відкриває та ховає блок `#extra-details` із додатковою інформацією про зали та знижки.
   - Перемикається CSS-клас `.is-hidden`, змінюється текст кнопки та оновлюється атрибут доступності `aria-expanded` (`true` / `false`).
2. **Додавання картки фільму в обране («Додати в обране» / «В обраному»):**
   - Кнопка `.favorite-button` у картці фільму «Дюна: Частина друга» перемикає активний стан `.is-active`.
   - Змінюється текстовий вміст кнопки та оновлюється атрибут `aria-pressed` (`true` / `false`).

## Використані DOM-методи та події
- `document.querySelector()` — пошук кнопок та інформаційного блоку за CSS-селекторами.
- `element.addEventListener("click", ...)` — обробка події кліку мишею та активації з клавіатури.
- `element.classList.toggle()` — перемикання класів стану `.is-hidden` та `.is-active`.
- `element.textContent` — безпечна зміна тексту кнопок відповідно до поточного стану.
- `element.setAttribute()` — синхронізація ARIA-атрибутів (`aria-expanded`, `aria-pressed`).
